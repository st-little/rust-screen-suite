# Rust Screen Suite

A collection of Rust-based applications for monitoring and managing game screens, especially for the game "Rust".

## Overview

This repository contains multiple Windows applications built with Rust and Dioxus, designed to help users monitor, analyze, and manage screens from the game Rust and similar titles.

## Features

- Real-time screen monitoring for the game Rust
- Alert management and notification tools
- Modular design for adding more monitoring utilities
