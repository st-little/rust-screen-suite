알림 모니터링 가이드

이 가이드는 "에어드롭 감지됨" 알림을 예시로 앱 설정 방법을 설명합니다.

1단계: 템플릿 준비

  1. Rust 게임에서 "에어드롭 감지됨" 알림이 표시되면 게임 화면을 캡처하세요.
  2. 캡처한 이미지에서 알림 영역을 잘라내어 이미지 파일로 저장하세요.

2단계: 언어 및 시간대 설정

  1. 헤더의 "설정" 아이콘을 클릭하여 설정 화면을 엽니다.
  2. 사이드바에서 "일반" 탭을 선택합니다.
  3. "언어" 드롭다운에서 원하는 언어를 선택합니다.
  4. "시간대" 드롭다운에서 자신의 시간대를 선택합니다.
  5. 화면 하단의 "저장" 버튼을 클릭하여 설정을 저장합니다.

3단계: 템플릿 설정

  1. 사이드바에서 "템플릿" 탭을 선택합니다.
  2. "에어드롭 감지됨"의 "파일 선택" 버튼을 클릭하고 1단계에서 저장한 이미지를 선택합니다.
  3. 오른쪽의 미리보기 버튼으로 이미지가 올바른지 확인합니다.
  4. "저장" 버튼을 클릭합니다.

4단계: 모니터링할 알림 선택

  1. 사이드바에서 "알림" 탭을 선택합니다.
  2. "에어드롭 감지됨" 토글을 켭니다.
  3. "저장" 버튼을 클릭합니다.

5단계: 모니터링 설정 조정

알림 감지가 잘 되지 않을 경우 다음과 같이 설정을 조정하세요:

  1. 사이드바에서 "모니터링" 탭을 선택합니다.
  2. "감지 간격" 슬라이더로 감지 간격(밀리초)을 조정합니다.
  3. "감지 후 대기 시간" 슬라이더로 감지 후 대기 시간(밀리초)을 조정합니다.
  4. "임계값" 슬라이더로 템플릿 매칭 임계값을 조정합니다.
  5. "리사이즈 스케일" 슬라이더로 템플릿 매칭에 사용되는 이미지 축소 비율을 조정할 수 있습니다(값이 낮을수록 처리 속도가 빨라지지만 감지 정확도가 떨어질 수 있습니다).
  6. "저장" 버튼을 클릭합니다.

6단계: 알림 설정

  1. 사이드바에서 "알림" 탭을 선택합니다.
  2. 알림 감지 시 알림음을 재생하려면 "알림음" 토글을 켭니다.
  3. Discord 알림을 사용하려면 "Discord" 토글을 켜고 Webhook URL을 입력하세요(Discord 서버 설정에서 Webhook URL을 얻을 수 있습니다).
  4. "저장" 버튼을 클릭합니다.

7단계: 모니터링 시작 및 중지

  1. "모니터링 시작" 버튼을 클릭하여 알림 모니터링을 시작합니다.
  2. 알림이 감지되면 "알림 감지 기록"에 감지 시간과 알림 이름이 표시됩니다.
  3. 모니터링을 중지하려면 "모니터링 중지" 버튼을 클릭하세요.
