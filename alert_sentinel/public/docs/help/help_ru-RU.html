Руководство по мониторингу оповещений

В этом руководстве объясняется, как настроить приложение на примере оповещения "Обнаружен сброс груза".

Шаг 1: Подготовьте шаблон

  1. Когда в Rust появляется оповещение "Обнаружен сброс груза", сделайте снимок экрана игры.
  2. Обрежьте область оповещения на снимке экрана и сохраните её как изображение.

Шаг 2: Установите язык и часовой пояс

  1. Нажмите на значок "Настройки" в заголовке, чтобы открыть экран настроек.
  2. Выберите вкладку "Общие" в боковой панели.
  3. Выберите предпочитаемый язык в выпадающем списке "Язык".
  4. Выберите свой часовой пояс в выпадающем списке "Часовой пояс".
  5. Нажмите кнопку "Сохранить" внизу экрана, чтобы сохранить настройки.

Шаг 3: Установите шаблон

  1. Выберите вкладку "Шаблон" в боковой панели.
  2. Нажмите кнопку "Выбрать файл" для "Обнаружен сброс груза" и выберите изображение, сохранённое на шаге 1.
  3. Используйте кнопку предварительного просмотра справа, чтобы убедиться, что изображение верное.
  4. Нажмите кнопку "Сохранить".

Шаг 4: Выберите оповещения для мониторинга

  1. Выберите вкладку "Оповещения" в боковой панели.
  2. Включите переключатель для "Обнаружен сброс груза".
  3. Нажмите кнопку "Сохранить".

Шаг 5: Настройте параметры мониторинга

Если обнаружение оповещений работает некорректно, настройте параметры следующим образом:

  1. Выберите вкладку "Мониторинг" в боковой панели.
  2. Отрегулируйте интервал обнаружения (миллисекунды) с помощью ползунка "Интервал обнаружения".
  3. Отрегулируйте время ожидания после обнаружения (миллисекунды) с помощью ползунка "Время ожидания после обнаружения".
  4. Отрегулируйте порог совпадения шаблона с помощью ползунка "Порог".
  5. Вы можете отрегулировать ползунок "Масштаб изменения размера", чтобы изменить коэффициент уменьшения изображения для сопоставления шаблонов (меньшие значения ускоряют обработку, но могут снизить точность обнаружения).
  6. Нажмите кнопку "Сохранить".

Шаг 6: Настройте уведомления

  1. Выберите вкладку "Уведомления" в боковой панели.
  2. Чтобы воспроизводить звуковое уведомление при обнаружении оповещения, включите переключатель "Звук уведомления".
  3. Чтобы использовать уведомления Discord, включите переключатель "Discord" и введите свой Webhook URL (его можно получить в настройках сервера Discord).
  4. Нажмите кнопку "Сохранить".

Шаг 7: Запуск и остановка мониторинга

  1. Нажмите кнопку "Начать мониторинг", чтобы начать мониторинг оповещений.
  2. Когда оповещение обнаружено, время обнаружения и имя оповещения появятся в "Истории обнаружения оповещений".
  3. Чтобы остановить мониторинг, нажмите кнопку "Остановить мониторинг".
