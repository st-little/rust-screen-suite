Alert Monitoring Guide

This guide explains how to set up the application using the "Airdrop Detected" alert as an example.

Step 1: Prepare the Template

  1. When the "Airdrop Detected" alert appears in Rust, take a screenshot of the game screen.
  2. Crop the alert area from the screenshot and save it as an image file.

Step 2: Set Language and Timezone

  1. Click the "Settings" icon in the header to open the settings screen.
  2. Select the "General" tab from the sidebar.
  3. Select your preferred language from the "Language" dropdown.
  4. Select your timezone from the "Timezone" dropdown.
  5. Click the "Save" button at the bottom of the screen to save your settings.

Step 3: Set the Template

  1. Select the "Template" tab from the sidebar.
  2. Click the "Choose File" button for "Airdrop Detected" and select the image you saved in Step 1.
  3. Use the preview button on the right to confirm the image is correct.
  4. Click the "Save" button.

Step 4: Select Alerts to Monitor

  1. Select the "Alerts" tab from the sidebar.
  2. Turn on the toggle for "Airdrop Detected".
  3. Click the "Save" button.

Step 5: Adjust Monitoring Settings

If alert detection does not work well, adjust the settings as follows:

  1. Select the "Monitoring" tab from the sidebar.
  2. Adjust the detection interval (milliseconds) with the "Detection Interval" slider.
  3. Adjust the skip time after detection (milliseconds) with the "Skip Time After Detection" slider.
  4. Adjust the threshold for template matching with the "Threshold" slider.
  5. You can adjust the "Resize Scale" slider to change the image downscaling ratio used for template matching (lower values speed up processing but may reduce detection accuracy).
  6. Click the "Save" button.

Step 6: Set Up Notifications

  1. Select the "Notifications" tab from the sidebar.
  2. To play a notification sound when an alert is detected, turn on the "Notification Sound" toggle.
  3. To use Discord notifications, turn on the "Discord" toggle and enter your Webhook URL (you can get the Webhook URL from your Discord server settings).
  4. Click the "Save" button.

Step 7: Start and Stop Monitoring

  1. Click the "Start Monitoring" button to begin monitoring alerts.
  2. When an alert is detected, the detection time and alert name will appear in the "Alert Detection History".
  3. To stop monitoring, click the "Stop Monitoring" button.
