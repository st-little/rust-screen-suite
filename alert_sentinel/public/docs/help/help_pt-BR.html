Guia de Monitoramento de Alertas

Este guia explica como configurar o aplicativo usando o alerta "Airdrop Detectado" como exemplo.

Passo 1: Prepare o Modelo

  1. Quando o alerta "Airdrop Detectado" aparecer no Rust, tire uma captura de tela do jogo.
  2. Recorte a área do alerta da captura de tela e salve como um arquivo de imagem.

Passo 2: Defina o Idioma e o Fuso Horário

  1. Clique no ícone "Configurações" no cabeçalho para abrir a tela de configurações.
  2. Selecione a guia "Geral" na barra lateral.
  3. Selecione o idioma desejado no menu suspenso "Idioma".
  4. Selecione seu fuso horário no menu suspenso "Fuso Horário".
  5. Clique no botão "Salvar" na parte inferior da tela para salvar as configurações.

Passo 3: Defina o Modelo

  1. Selecione a guia "Modelo" na barra lateral.
  2. Clique no botão "Escolher Arquivo" para "Airdrop Detectado" e selecione a imagem salva no Passo 1.
  3. Use o botão de visualização à direita para confirmar se a imagem está correta.
  4. Clique no botão "Salvar".

Passo 4: Selecione os Alertas para Monitorar

  1. Selecione a guia "Alertas" na barra lateral.
  2. Ative a opção para "Airdrop Detectado".
  3. Clique no botão "Salvar".

Passo 5: Ajuste as Configurações de Monitoramento

Se a detecção de alertas não funcionar bem, ajuste as configurações da seguinte forma:

  1. Selecione a guia "Monitoramento" na barra lateral.
  2. Ajuste o intervalo de detecção (milissegundos) com o controle deslizante "Intervalo de Detecção".
  3. Ajuste o tempo de espera após a detecção (milissegundos) com o controle deslizante "Tempo de Espera Após Detecção".
  4. Ajuste o limite para correspondência de modelo com o controle deslizante "Limite".
  5. Você pode ajustar o controle deslizante "Escala de Redimensionamento" para alterar a taxa de redução da imagem usada para correspondência de modelo (valores menores aceleram o processamento, mas podem reduzir a precisão da detecção).
  6. Clique no botão "Salvar".

Passo 6: Configure as Notificações

  1. Selecione a guia "Notificações" na barra lateral.
  2. Para reproduzir um som de notificação quando um alerta for detectado, ative a opção "Som de Notificação".
  3. Para usar notificações do Discord, ative a opção "Discord" e insira sua URL do Webhook (você pode obter a URL do Webhook nas configurações do seu servidor Discord).
  4. Clique no botão "Salvar".

Passo 7: Iniciar e Parar o Monitoramento

  1. Clique no botão "Iniciar Monitoramento" para começar a monitorar alertas.
  2. Quando um alerta for detectado, o horário de detecção e o nome do alerta aparecerão no "Histórico de Detecção de Alertas".
  3. Para parar o monitoramento, clique no botão "Parar Monitoramento".
