คู่มือการตรวจสอบการแจ้งเตือน

คู่มือนี้อธิบายวิธีตั้งค่าแอปพลิเคชันโดยใช้ตัวอย่าง "ตรวจพบ Airdrop"

ขั้นตอนที่ 1: เตรียมเทมเพลต

  1. เมื่อมีการแจ้งเตือน "ตรวจพบ Airdrop" ในเกม Rust ให้จับภาพหน้าจอของเกม
  2. ครอบตัดพื้นที่แจ้งเตือนจากภาพหน้าจอและบันทึกเป็นไฟล์รูปภาพ

ขั้นตอนที่ 2: ตั้งค่าภาษาและเขตเวลา

  1. คลิกไอคอน "การตั้งค่า" ที่ส่วนหัวเพื่อเปิดหน้าการตั้งค่า
  2. เลือกแท็บ "ทั่วไป" จากแถบด้านข้าง
  3. เลือกภาษาที่ต้องการจากเมนูแบบเลื่อนลง "ภาษา"
  4. เลือกเขตเวลาของคุณจากเมนูแบบเลื่อนลง "เขตเวลา"
  5. คลิกปุ่ม "บันทึก" ที่ด้านล่างของหน้าจอเพื่อบันทึกการตั้งค่า

ขั้นตอนที่ 3: ตั้งค่าเทมเพลต

  1. เลือกแท็บ "เทมเพลต" จากแถบด้านข้าง
  2. คลิกปุ่ม "เลือกไฟล์" สำหรับ "ตรวจพบ Airdrop" และเลือกภาพที่บันทึกไว้ในขั้นตอนที่ 1
  3. ใช้ปุ่มแสดงตัวอย่างทางขวาเพื่อตรวจสอบว่าภาพถูกต้องหรือไม่
  4. คลิกปุ่ม "บันทึก"

ขั้นตอนที่ 4: เลือกการแจ้งเตือนที่ต้องการตรวจสอบ

  1. เลือกแท็บ "การแจ้งเตือน" จากแถบด้านข้าง
  2. เปิดสวิตช์สำหรับ "ตรวจพบ Airdrop"
  3. คลิกปุ่ม "บันทึก"

ขั้นตอนที่ 5: ปรับการตั้งค่าการตรวจสอบ

หากการตรวจจับการแจ้งเตือนไม่แม่นยำ ให้ปรับการตั้งค่าตามนี้:

  1. เลือกแท็บ "การตรวจสอบ" จากแถบด้านข้าง
  2. ปรับช่วงเวลาการตรวจจับ (มิลลิวินาที) ด้วยแถบเลื่อน "ช่วงเวลาการตรวจจับ"
  3. ปรับเวลาข้ามหลังการตรวจจับ (มิลลิวินาที) ด้วยแถบเลื่อน "เวลาข้ามหลังการตรวจจับ"
  4. ปรับเกณฑ์สำหรับการจับคู่เทมเพลตด้วยแถบเลื่อน "เกณฑ์"
  5. คุณสามารถปรับแถบเลื่อน "อัตราส่วนการย่อขนาด" เพื่อเปลี่ยนอัตราการย่อขนาดของภาพที่ใช้สำหรับการจับคู่เทมเพลต (ค่าน้อยจะประมวลผลเร็วขึ้นแต่ความแม่นยำอาจลดลง)
  6. คลิกปุ่ม "บันทึก"

ขั้นตอนที่ 6: ตั้งค่าการแจ้งเตือน

  1. เลือกแท็บ "การแจ้งเตือน" จากแถบด้านข้าง
  2. หากต้องการเล่นเสียงแจ้งเตือนเมื่อมีการตรวจพบ ให้เปิดสวิตช์ "เสียงแจ้งเตือน"
  3. หากต้องการใช้การแจ้งเตือน Discord ให้เปิดสวิตช์ "Discord" และป้อน Webhook URL ของคุณ (สามารถรับได้จากการตั้งค่าเซิร์ฟเวอร์ Discord)
  4. คลิกปุ่ม "บันทึก"

ขั้นตอนที่ 7: เริ่มและหยุดการตรวจสอบ

  1. คลิกปุ่ม "เริ่มการตรวจสอบ" เพื่อเริ่มตรวจสอบการแจ้งเตือน
  2. เมื่อมีการตรวจพบการแจ้งเตือน เวลาตรวจพบและชื่อการแจ้งเตือนจะแสดงใน "ประวัติการตรวจพบการแจ้งเตือน"
  3. หากต้องการหยุดการตรวจสอบ ให้คลิกปุ่ม "หยุดการตรวจสอบ"
