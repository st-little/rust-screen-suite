Guide de surveillance des alertes

Ce guide explique comment configurer l'application en utilisant l'alerte "Airdrop détecté" comme exemple.

Étape 1 : Préparer le modèle

  1. Lorsque l'alerte "Airdrop détecté" apparaît dans Rust, prenez une capture d'écran du jeu.
  2. Recadrez la zone d'alerte de la capture d'écran et enregistrez-la en tant que fichier image.

Étape 2 : Définir la langue et le fuseau horaire

  1. Cliquez sur l'icône "Paramètres" dans l'en-tête pour ouvrir l'écran des paramètres.
  2. Sélectionnez l'onglet "Général" dans la barre latérale.
  3. Sélectionnez votre langue préférée dans la liste déroulante "Langue".
  4. Sélectionnez votre fuseau horaire dans la liste déroulante "Fuseau horaire".
  5. Cliquez sur le bouton "Enregistrer" en bas de l'écran pour sauvegarder vos paramètres.

Étape 3 : Définir le modèle

  1. Sélectionnez l'onglet "Modèle" dans la barre latérale.
  2. Cliquez sur le bouton "Choisir un fichier" pour "Airdrop détecté" et sélectionnez l'image enregistrée à l'étape 1.
  3. Utilisez le bouton d'aperçu à droite pour vérifier que l'image est correcte.
  4. Cliquez sur le bouton "Enregistrer".

Étape 4 : Sélectionner les alertes à surveiller

  1. Sélectionnez l'onglet "Alertes" dans la barre latérale.
  2. Activez le bouton pour "Airdrop détecté".
  3. Cliquez sur le bouton "Enregistrer".

Étape 5 : Ajuster les paramètres de surveillance

Si la détection d'alerte ne fonctionne pas correctement, ajustez les paramètres comme suit :

  1. Sélectionnez l'onglet "Surveillance" dans la barre latérale.
  2. Ajustez l'intervalle de détection (millisecondes) avec le curseur "Intervalle de détection".
  3. Ajustez le temps d'attente après détection (millisecondes) avec le curseur "Temps d'attente après détection".
  4. Ajustez le seuil de correspondance de modèle avec le curseur "Seuil".
  5. Vous pouvez ajuster le curseur "Échelle de redimensionnement" pour modifier le taux de réduction d'image utilisé pour la correspondance de modèle (des valeurs plus faibles accélèrent le traitement mais peuvent réduire la précision de détection).
  6. Cliquez sur le bouton "Enregistrer".

Étape 6 : Configurer les notifications

  1. Sélectionnez l'onglet "Notifications" dans la barre latérale.
  2. Pour jouer un son de notification lorsqu'une alerte est détectée, activez le bouton "Son de notification".
  3. Pour utiliser les notifications Discord, activez le bouton "Discord" et saisissez votre URL Webhook (vous pouvez obtenir l'URL Webhook dans les paramètres de votre serveur Discord).
  4. Cliquez sur le bouton "Enregistrer".

Étape 7 : Démarrer et arrêter la surveillance

  1. Cliquez sur le bouton "Démarrer la surveillance" pour commencer à surveiller les alertes.
  2. Lorsqu'une alerte est détectée, l'heure de détection et le nom de l'alerte apparaîtront dans "Historique de détection d'alerte".
  3. Pour arrêter la surveillance, cliquez sur le bouton "Arrêter la surveillance".
