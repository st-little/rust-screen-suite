アラート監視の手順

ここでは「エアドロップが降下」のアラートを例に、アプリの設定方法を説明します。

Step1: テンプレートの準備

  1. Rustのゲーム画面で「エアドロップが降下」のアラートが表示されたらスクリーンショットを撮ります。
  2. スクリーンショットからアラート部分をトリミングして画像として保存します。

Step2: 言語・タイムゾーンの設定

  1. ヘッダーの「設定」アイコンをクリックして設定画面を開きます。
  2. サイドバーから「一般」タブを選択します。
  3. 「言語」セレクトボックスで使用する言語を選択します。
  4. 「タイムゾーン」セレクトボックスで自分のタイムゾーンを選択します。
  5. 画面下部の「保存」ボタンをクリックして設定を保存します。

Step3: テンプレートの設定

  1. サイドバーから「テンプレート」タブを選択します。
  2. 「エアドロップが降下」の「ファイルの選択」ボタンをクリックし、Step1で保存した画像を選択します。
  3. 右側のプレビューボタンで画像が正しいか確認します。
  4. 「保存」ボタンをクリックします。

Step4: 監視するアラートの選択

  1. サイドバーから「アラート」タブを選択します。
  2. 「エアドロップが降下」のトグルをオンにします。
  3. 「保存」ボタンをクリックします。

Step5: 監視設定の調整

アラート検知がうまくいかない場合は、以下の手順で設定を調整してください。

  1. サイドバーから「監視」タブを選択します。
  2. 「監視間隔」スライダーで検知間隔（ミリ秒）を調整します。
  3. 「検知後のスキップ時間」スライダーで次の検知までの待機時間（ミリ秒）を調整します。
  4. 「しきい値」スライダーでテンプレートとゲーム画面の一致度のしきい値を調整します。
  5. 「リサイズスケール」スライダーで、テンプレートマッチング時に使用する画像の縮小率を調整できます（値を小さくすると処理が高速になりますが、検知精度が下がる場合があります）。
  6. 「保存」ボタンをクリックします。

Step6: 検知通知の設定

  1. サイドバーから「通知」タブを選択します。
  2. アラート検知時に通知音を鳴らしたい場合は「通知音」トグルをオンにします。
  3. Discord通知を利用する場合は「Discord」トグルをオンにし、Webhook URLを入力します（Webhook URLはDiscordのサーバー設定から取得できます）。
  4. 「保存」ボタンをクリックします。

Step7: アラート監視の開始・停止

  1. 「監視開始」ボタンをクリックしてアラート監視を開始します。
  2. アラートを検知すると、「アラート検知履歴」に検知時刻とアラート名が表示されます。
  3. 監視を停止する場合は「監視停止」ボタンをクリックします。
