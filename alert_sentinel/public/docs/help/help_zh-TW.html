警報監控指南

本指南以「空投已偵測」警報為例，說明如何設定本應用程式。

步驟1：準備模板

  1. 當Rust遊戲中出現「空投已偵測」警報時，截取遊戲畫面。
  2. 從截圖中裁剪出警報區域並儲存為圖片檔案。

步驟2：設定語言和時區

  1. 點擊標題列的「設定」圖示以開啟設定畫面。
  2. 從側邊欄選擇「一般」分頁。
  3. 在「語言」下拉選單中選擇您偏好的語言。
  4. 在「時區」下拉選單中選擇您的時區。
  5. 點擊畫面底部的「儲存」按鈕以儲存設定。

步驟3：設定模板

  1. 從側邊欄選擇「模板」分頁。
  2. 點擊「空投已偵測」的「選擇檔案」按鈕，選擇步驟1儲存的圖片。
  3. 使用右側的預覽按鈕確認圖片是否正確。
  4. 點擊「儲存」按鈕。

步驟4：選擇要監控的警報

  1. 從側邊欄選擇「警報」分頁。
  2. 開啟「空投已偵測」的切換開關。
  3. 點擊「儲存」按鈕。

步驟5：調整監控設定

如果警報偵測效果不佳，請依下列方式調整設定：

  1. 從側邊欄選擇「監控」分頁。
  2. 使用「偵測間隔」滑桿調整偵測間隔（毫秒）。
  3. 使用「偵測後跳過時間」滑桿調整偵測後的等待時間（毫秒）。
  4. 使用「閾值」滑桿調整模板比對的閾值。
  5. 可透過「縮放比例」滑桿調整用於模板比對的圖片縮小比例（較小的值處理速度較快，但可能降低偵測精度）。
  6. 點擊「儲存」按鈕。

步驟6：設定通知

  1. 從側邊欄選擇「通知」分頁。
  2. 如需在偵測到警報時播放通知音，請開啟「通知音」開關。
  3. 如需使用Discord通知，請開啟「Discord」開關並輸入您的Webhook URL（可於Discord伺服器設定中取得）。
  4. 點擊「儲存」按鈕。

步驟7：開始與停止監控

  1. 點擊「開始監控」按鈕以開始監控警報。
  2. 偵測到警報時，「警報偵測歷史」中會顯示偵測時間與警報名稱。
  3. 要停止監控，請點擊「停止監控」按鈕。
