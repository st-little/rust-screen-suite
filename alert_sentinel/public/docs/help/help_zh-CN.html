警报监控指南

本指南以“空投已检测”警报为例，说明如何设置本应用程序。

步骤1：准备模板

  1. 当Rust游戏中出现“空投已检测”警报时，截取游戏画面。
  2. 从截图中裁剪出警报区域并保存为图片文件。

步骤2：设置语言和时区

  1. 点击标题栏的“设置”图标打开设置界面。
  2. 从侧边栏选择“一般”标签。
  3. 在“语言”下拉框中选择您喜欢的语言。
  4. 在“时区”下拉框中选择您的时区。
  5. 点击页面底部的“保存”按钮以保存设置。

步骤3：设置模板

  1. 从侧边栏选择“模板”标签。
  2. 点击“空投已检测”的“选择文件”按钮，选择第1步保存的图片。
  3. 使用右侧的预览按钮确认图片是否正确。
  4. 点击“保存”按钮。

步骤4：选择要监控的警报

  1. 从侧边栏选择“警报”标签。
  2. 打开“空投已检测”的开关。
  3. 点击“保存”按钮。

步骤5：调整监控设置

如果警报检测效果不佳，请按以下方式调整设置：

  1. 从侧边栏选择“监控”标签。
  2. 使用“检测间隔”滑块调整检测间隔（毫秒）。
  3. 使用“检测后跳过时间”滑块调整检测后的等待时间（毫秒）。
  4. 使用“阈值”滑块调整模板匹配的阈值。
  5. 可以通过“缩放比例”滑块调整用于模板匹配的图片缩小比例（较小的值处理速度更快，但可能降低检测精度）。
  6. 点击“保存”按钮。

步骤6：设置通知

  1. 从侧边栏选择“通知”标签。
  2. 如需在检测到警报时播放通知音，请打开“通知音”开关。
  3. 如需使用Discord通知，请打开“Discord”开关并输入您的Webhook URL（可在Discord服务器设置中获取）。
  4. 点击“保存”按钮。

步骤7：开始和停止监控

  1. 点击“开始监控”按钮以开始监控警报。
  2. 检测到警报时，“警报检测历史”中会显示检测时间和警报名称。
  3. 要停止监控，请点击“停止监控”按钮。
